실거래 연결 순서

  1. 실행 서버 준비

    업비트에 허용 IP를 등록할 수 있고 계속 켜져 있는 PC 또는 서버를 사용하세요.

  2. 서버에 API 키 설정

    자산조회·주문조회·주문하기 권한이 필요합니다. 키는 실행 서버의 환경변수로만 설정하며 출금 권한은 사용하지 않습니다.

  3. Sites와 엔진 연결

    Sites의 서버 설정에 ENGINE_URL과 비밀값 ENGINE_TOKEN을 등록합니다. 브라우저에는 키나 토큰이 전달되지 않습니다.

  4. 연결 점검 후 운용 시작

    실거래 엔진은 신규 진입이 중단된 상태로 시작합니다. 한도를 확인하고 트레이딩 화면에서 시작하세요.
